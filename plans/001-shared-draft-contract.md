# Shared draft ownership

One Home-lifetime SharedDraftSession borrows the existing WorkspaceEntrySession,
registry, composer and Android share queue. The destination route borrows this
same owner; it renders immutable copied disclosure/destination/recovery facts.
The owner coordinates verified target, exact missing-session recovery, paging,
create-once retry, durable staging and native acknowledgement. It introduces no
second draft store, queue codec or transport authority.

Offer, entry, profile selection and exact selected chat fence asynchronous work
and navigation. A native ACK already admitted may settle; it cannot navigate to
a subsequently selected chat. Failed staging reuses its prepared target. Cancel
and failed discard preserve incoming content. Departing routes may read their
last published immutable facts after commands retire; this grants no authority.

Existing review/Home/restore assertions and one actual held-ACK control verify
these properties. The dependency linter and26 exact retired declarations protect
the removed raw UI workflow. Both PR/release workflows enforce the new rule.
Native/device and final whole-program acceptance remain separately required.
