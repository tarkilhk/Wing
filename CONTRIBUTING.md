# Contributing

Read [Get started](docs/GETTING_STARTED.md) and [Explore Wing](docs/FEATURES.md)
for the current user experience. The [guide index](docs/README.md) covers
individual tasks.

Use [Wing's issues](https://github.com/tarkilhk/Wing/issues) for reproducible client
bugs. Include Android and Wing versions, the Hermes revision if known, expected
behavior and minimal steps. Follow [Security](SECURITY.md) before attaching logs
or screenshots.

Engineering plans, specifications and development procedures are maintained in
the project's private workspace. For agent work, start with [AGENTS.md](AGENTS.md)
and obtain workspace access from the project owner.

Preserve the MIT attribution and applicable third-party license notices.
See [Attribution and license](NOTICE.md), and record the license of any new
third-party component.
