Watch tools and delegated agents

Open Activity to switch between the tool timeline, tasks and delegated agents.

Open an agent to read its task and live output. Send a correction to that agent or stop its work from the same view.

Past chats retain saved activity when Hermes supplies it.

Steer, queue or stop

Type an instruction, then hold the send control, slide to an action and release. Steer sends it to work in progress. Queue keeps it for later; you can edit it before it sends.

Use Stop to interrupt an active run. You can also edit a saved message, regenerate an answer or branch into a separate conversation.

Inspect tool requests and results

Expand a tool call to see what was requested and what it returned. Code execution shows code and output. Other calls can show file contents, changes, search matches or structured data.

Copy the code or output separately, wrap long lines, or open a full view. File and image results have preview and share actions. Raw details shows the supplied inputs and output.

Send files, photos or a dictated message

Attach a file or photo, take a picture in the chat, or send content to Wing from another Android app. Review attachments before sending.

Dictation writes into an editable draft, so you can check and change the words first.

Reconnect to ongoing work

Work accepted by Hermes can continue while your phone is disconnected. Reconnect to follow it or send another instruction. New messages and live controls need a connection.
