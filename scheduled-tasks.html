Create or edit a schedule

Open Scheduled tasks in Administration. Start from a server template or write your own instructions. Choose a recurring schedule, a one-time run or a custom expression.

Choose the model and where results should be delivered from the options your server provides. Save on server stores results on Hermes.

Recurring schedules use Hermes time. Run timestamps are shown in phone time.

Find, pause or run a task

Search the list or filter by All, Active, Paused or Needs attention. Open a task to see its instructions, next run and recent history.

Pause a schedule to prevent future runs. It does not stop work already underway. Use Run now to start a task immediately. A paused task asks you to resume it first.

Review recent runs

Open an agent run to read its conversation. Script runs show the returned status, timestamp and output or error in the task details.

You can leave the task details while a run continues, then return to check the result.
