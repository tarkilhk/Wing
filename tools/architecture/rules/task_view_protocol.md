# ARCH_TASK_VIEW_PROTOCOL semantic SDK contract

This independent rule checks scheduled-task views. Its finite property is canonical protocol method calls and tearoffs; not command lifetime. Syntax selects candidates; resolved canonical library/declaration identity decides findings. Existing fixtures cover the applicable aliases, barrels, parts, cascades and valid unrelated symbols. Dynamic candidate operations and unproved conditional dependencies return input exit 2. Runtime races remain behavioral-test properties.

The mandatory complete-scope architecture aggregate enforces production scope. The pure fixture runner proves resolver behavior separately; a clean zero-candidate production run cannot prove resolution.

```sh
dart run tools/architecture/rules/task_view_protocol.dart --json
dart compile exe tools/architecture/rules/task_view_protocol.dart -o build/task_view_protocol
dart run tools/architecture/tests/task_view_protocol_test.dart --compiled build/task_view_protocol
```

Source and compiled runners use the existing shared `tools/architecture/dart_sdk.dart`. An explicit `--sdk PATH` is validated before the no-candidate shortcut; invalid SDK input exits 2. Standalone compiled fixtures outside a configured Flutter checkout receive the real SDK explicitly. The public proof runner checks source and freshly compiled invalid (1), valid (0) and unverifiable (2) CLI cases with exact diagnostic ID/file/line, and an invalid explicit SDK on a valid no-candidate fixture. SDK failure cannot count as the intended violation proof.

Keep source/helper/SDK/binary hashes and repeated cold/warm process evidence under ignored `build/` or private acceptance storage. Complete-scope correctness and compiled semantic correctness are separate from feedback timing. Complete authored production scope passes fresh source and compiled checks. The local feedback budgets remain 15 seconds for a source process and 1 second for a compiled process on the recorded host/SDK; repeated quiet acceptance, source/SDK/binary hashes and scope are stored privately. Compare regressions under the same conditions and optimize a repeated breach rather than raising these budgets. No timing observation changes deterministic exit status.

Bare inherited capability captures are getter-context candidates and require the
same resolved canonical declaration identity as qualified calls or tearoffs. A
same-named local callback remains valid. Dedicated invalid/valid fixtures protect
this pair; named argument labels are not getter accesses. The preserved SDK-only
source CLI incorrectly exited 0 for the canonical bare inherited capture before
this selection correction.

## Parsed lexical prefilter

`lexical_bindings.dart` can prove a bare getter-context name binds to an explicit
own-class field/getter or body-local formal parameter. These declarations are
not spelling exemptions: the AST must contain the matching declaration in the
actual enclosing scope. Own-class field/getter exemptions never apply in
canonical owner libraries (including their parts). Traversal retains canonical accesses in every initializer and
getter body. Inherited, unknown and qualified accesses still use resolved
provenance. Fixtures cover own fields/getters, parameter and closure shadowing,
inherited closure capture, inherited consumer parts and canonical initializer/
getter-body accesses. The actual source and compiled CLI additionally prove an
inherited closure violation and a legitimate own-field read.
