# Workspace voice namespace

ARCH_WORKSPACE_VOICE_VIEW_DEPENDENCIES checks the canonical workspace view and
its actual parts/barrels for the raw Hermes speech adapter. Native VoiceDevice
factory injection remains genuine route composition. Captured target, speech
processing, arbitration and draft admission belong to the existing owners.

Run `dart run tools/architecture/rules/workspace_voice_view_dependencies.dart`.
Exit0 is clean,1 is a violation,2 is invalid/unsupported input. Five finite
fixtures include direct/prefixed/barrel dependencies, accepted owner/native
composition and missing canonical input. Required CI gates run the command.

This namespace rule does not prove cancellation, native resource outcomes or
exact text revisions. Public-owner-state protects seven private authoritative
voice facts, exact retirement six removed declarations, and focused controls
protect actual arbitration and edit-away/back completion regressions.
