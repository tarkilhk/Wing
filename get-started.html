Before you start

You need an Android phone running Android 7.0 or newer, plus one of these:

  • Hermes Cloud: a Nous Portal account with an instance you can open.
  • Your own server: a working Hermes installation with its dashboard and Desktop Gateway enabled, a configured model provider, and an address your phone can reach.

Try a message in Hermes first. Wing connects to that agent; a model-provider API key alone is not enough. Wing is free, with every feature included. Your server and model provider may have their own costs.

Setting up a server for the first time? Follow the self-hosting guide, then return here.

Install and connect

  1. Install the Android app

    Download a signed APK from the latest release. Choose arm64-v8a for most current phones. Open the downloaded file; Android may ask you to allow installation from your browser or file manager.

  2. Choose how to reach Hermes

    Open Wing and tap Connect your agent.

    Hermes Cloud: sign in through Nous Portal, then choose your organization and instance.

    Use an address: enter the full dashboard address, including its port or path if it has one. For example, http://hermes.home:9119 on your private network, or https://hermes.example.com/hermes. Use your dashboard username and password if sign-in is enabled.

    The address must work from your phone. localhost points to the phone itself. Do not add /api or /ws. For access away from home, use HTTPS or an encrypted private network.

    Most connections do not need Custom setup. Use it only when your server requires proxy headers, proxy-managed sign-in or a separate live-chat address.

  3. Check, then save

    Run Check connection. Wing checks profile access, live chat and history separately. When all three pass, name your connection and choose Save and open.

    If a check fails, find the matching fix below, correct the setup and check again.

Get your first reply

  1. Choose a profile and open a chat

    In Chats, choose the Hermes profile you want to use, then create a chat. Each profile has its own instructions, tools and model settings.

  2. Send a small request

    Try “Give me three ideas for a quick lunch.” Wait for the reply to finish. Connection checks verify access; this step confirms the selected profile can actually answer.

  3. Find the conversation again

    Return to Chats and reopen the conversation. Your message and reply should still be there. You are ready to start real work.

Next, organize chats into projects, talk to your bots, or follow several conversations with Recents. The side menu also opens Administration, Health and Analytics.

Fix the step that failed

The dashboard cannot be reached

Open the same address in your phone's browser. Check the hostname, port and network or VPN connection. A dashboard listening only on 127.0.0.1 is reachable only on its own server. If the address redirects, use its final address in Wing.

Sign-in or profile access fails

Use your Hermes dashboard login, not your model-provider API key. If a proxy handles sign-in, check its requirements in Custom setup. For Cloud, confirm you selected the intended organization and instance.

Profiles load, but live chat or history fails

Make sure the Desktop Gateway is running on the same Hermes installation. Your proxy must pass live-chat WebSocket connections as well as dashboard requests. The self-hosting guide covers the routes and proxy setup.

Everything connects, but there is no reply

Try the same profile directly in Hermes. Check its model provider and credentials on the server. If the profile works there, open Health in Wing to inspect the connection.

Offline use, notifications and backups

Hermes can continue accepted work while your phone is disconnected. New messages and live controls need a connection. Some recently loaded chats can be read offline.

For screen-off notifications, allow background battery use and reopen Wing after restarting the phone. Android restrictions, force-stop and network loss can interrupt delivery.

Configuration backups include connections, credentials and preferences, with optional passphrase encryption. Conversations stay on Hermes; drafts and queues are excluded. Before upgrading, check the release notes for changes that affect unsent work.

Privacy

The Wing maintainer does not relay your conversations. Your chosen Hermes server and model providers process your content. Connection details and app preferences are stored on your device.
