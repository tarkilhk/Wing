Check CPU, memory and disk

Host shows available CPU, memory and disk readings, uptime and load. Open the machine details for more information or refresh the readings.

Missing measurements stay unavailable. If a refresh fails, the last reading keeps its timestamp.

Run diagnostics and read logs

Run Doctor or a security audit, then open the result to read the findings. Filter server logs by category and severity, or search for a particular error.

Check the selected profile

Profile checks cover model access, tool setup, MCP connectors and scheduled tasks. Switch profiles in the header to check another agent.

Use Fix access to open the account editor when credentials are missing. Retry incomplete checks from Health.

What the checks establish

Model access checks whether credentials are available; it does not send a model request or check remaining quota. Tool setup checks configuration. Connector checks test a connection, not every tool action. Schedule checks report recorded problems without running the tasks.

Each check reports its own result. Open What's checked? in Health for the details.
