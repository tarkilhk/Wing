A profile with a purpose.

Choose the profile before changing its supported settings. Edit the agent’s description and instructions, set its model defaults and reasoning options, and adjust memory budgets and supported behavior.

Profile defaults apply to new conversations. The model for an existing conversation has its own control in Chats.

Create, clone configuration, rename or delete supported profiles from Manage profiles. Profile colors are local to this device and connection, helping you recognize the agent throughout Wing.

Put the right capabilities in reach.

Browse installed skills and their formatted instructions. Inspect provenance, discover skills through the official Hub, and use supported installation and update controls.

Skills and tools separates enabled capabilities from the ones that need setup. MCP connectors bring external tools and sources into your agent’s setup. Provider access and connectors have their own settings and status, so credentials and integrations stay with the intended profile.

Give recurring work a place.

Manage server-run scheduled tasks for the profile: search and filter the list, open instructions, create or edit a schedule, and review recent runs.

Choose from supported schedules and server templates. Pause, resume or run a task when you need to. Hermes executes the work; Wing gives you the controls and returned results.

A recent run can open its conversation or show supplied script output. A paused schedule does not stop a run already underway.

Find a setting. Keep its context.

Search Administration using the task you have in mind. Results show the setting’s location and take you to the relevant field.

Editors identify their target and unsaved changes. Failed or uncertain saves retain the form and its explanation. Wing reads back supported changes so a submitted request is not confused with a confirmed result.

Understand where the work goes.

Hermes analytics shows activity, token trends and model breakdowns across available time ranges. Estimated costs and subscription API-equivalent values are labeled as estimates.

Health is a separate destination for host resources, diagnostics and profile checks.
