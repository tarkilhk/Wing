# Implemented-feature QA sweep

New feature work is paused until the implemented roadmap has been checked,
recorded failures have been fixed and failed checks have passed on retest.
The scope is W00 and the implemented portions of D01-D30 in the
[delivery sequence](DELIVERY_SEQUENCE.md). Deferred features remain deferred.

Use the disposable emulator for routine checks. Production widgets and native
plugins may use isolated gateway data; label that evidence as synthetic.
Use the phone only for a reported live issue, Samsung-specific behavior or final
deployment. No Hermes backend code changes are permitted. Real server mutations
are separate from isolated fixture tests.

## Baseline and execution

- Production baseline: 2.31.1, with 1,288 unit/widget tests passing and four opt-in
  skips. Its analyzer and four emulator scenarios passed before this sweep.
- The sweep reproduced five client defects: Markdown file links, direct-open read
  state, invalid subagent/process snapshots and blank native SVG rendering.
  The signed patch is 2.31.2 / base 2187, ARM64 build 21872. Package identity,
  signature and non-debuggable release status are verified. Installed in place
  on the Samsung phone on 2026-09-13; Android reports 2.31.2 / 21872.
- A fresh baseline run passed all 1,288 tests with four opt-in skips and clean
  analysis. After the fixes, all 83 checks in the affected files and release
  identity checks passed. The full post-fix suite then passed 1,293 tests with
  four opt-in skips. The final run including the native image fix also passed
  1,293 tests in `build/2.31.2-full-tests-final.log`; analysis is clean in
  `build/2.31.2-analyze-verified.log`.
- Earlier native and live evidence remains in
  [emulator verification](EMULATOR_ROADMAP_VERIFICATION.md) and
  [phone acceptance](LIVE_PHONE_ACCEPTANCE_2026-09-12.md).
- Coverage review is in progress across every implemented delivery slice.
  Existing tests alone do not close a missing native or server-contract check.
- All seven expanded emulator scenarios passed in
  `build/2.31.2-emulator-seven-isolated-retry.log`, driver exit 0. No new feature
  work has started. Live-server and Samsung-only acceptance remains open.
- The final 2.31.9 suite passes 1,331 tests with four opt-in skips in
  `build/2.31.9-final-full-tests.log`. Final analysis is clean after 27.1 s in
  `build/2.31.9-final-analysis.log`.
