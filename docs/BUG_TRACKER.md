The credential redirect and queued attachment fixes passed regression tests. Their closed issues link to the commits that integrated them.

The new-connection probe bounds each verification stage and closes provisional resources on timeout/cancellation. `DashboardReadTransport` also bounds dashboard reads and downloads; write paths in `DashboardClient` still contain unbounded authorization/request awaits. The older issue #4 description predates these read improvements.

`ComposerSession.prepareDispatch` persists submission uncertainty before the controller submits a normal or queued prompt. Pending outgoing work is included in the durable outbox and uncertain queues pause rather than resubmitting automatically. This is implementation progress on #3; its device closure acceptance was not rerun during the code review. Connection recovery and recent reading snapshots do not recover every completion missed between global status snapshots (#9).

Backend issues are tracked here for their effect on Android. HUP-004 also has an existing upstream report and proposed fix; this cleanup did not post to upstream or modify the installed backend. See [Upstream Hermes bugs](UPSTREAM_HERMES_BUGS.md) for recorded versions and closure criteria.

[Good to know](KNOWN_LIMITATIONS.md) gives user-facing expectations. Missing Play hosting/declarations are release tasks, not additional runtime bugs.
