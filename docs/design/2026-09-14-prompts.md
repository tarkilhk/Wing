## A / Folio

Use case: ui-mockup. Create a polished high-fidelity static design proposal board for Hermes, an Android client for a general-purpose AI assistant. This is a design study, not a screenshot of an implemented app. Landscape board, large and crisp, roughly 3:2 aspect, with three equally sized portrait mobile screen artboards side by side. No phone hardware, perspective, shadows, gradients, illustrations, marketing slogans, or decorative logos. Tiny Android status and gesture areas. All UI copy must be legible. Board top: concept letter and name; beneath that small text "Hermes / Design study / 14 September 2026". Three labeled screens "Chats", "Conversation", "App settings"; under the screens a compact component specimen row showing primary "Save changes", secondary "Cancel", text "View details", disabled "Save changes", and a small light/dark palette pair. These are specimens, not an extra app toolbar.
Shared functional constraints: hamburger drawer navigation, absolutely no permanent bottom navigation bar. Projects are a scope inside Chats. No new features, metrics or dashboards. Standard Android sans body text 16dp, auxiliary labels 12-13dp, generous reading line height, 1.5dp line icons. Slim rectangular buttons, visible height about 40dp within 48dp tap areas, corner radius never over 8dp, no pill or capsule buttons anywhere, no floating circular plus. Inputs and composer also rectangular. Buttons must remain readable and practical for touch.
Screen 1 Chats: hamburger and "Chats" header with overflow; connection/profile line "Home / Personal" with dropdown; search "Search chats"; five compact one-line project rows under "Projects", names "Travel", "Home", "Reading", "Writing", "Learning"; small section action "See all". Then "Pinned" with "Japan itinerary" and subtitle "Ready for review"; then "Recent" with "Plan the weekend" / "Yesterday" and "Books for autumn" / "Monday". A modest "+ New chat" action belongs in the layout. Plenty of real list density; no project tile grid.
Screen 2 Conversation: back arrow, title "Japan itinerary", overflow, and small "Home / Personal" scope. Short user prompt "Plan three quiet days in Kyoto." Assistant response label "Hermes" then heading "A slower Kyoto" and readable text "Start early, keep afternoons open, and stay in one neighbourhood each day." Then "Day 1 / Eastern Kyoto" and text "Walk the Philosopher's Path before the crowds. Leave time for a small cafe." Collapsed line "3 sources checked" with chevron. A plain file row "Kyoto itinerary.pdf" with small document icon and open arrow. Small copy and more icons associated with the answer. At bottom a thin context-usage line integrated into the top edge of the composer, with a single small marker. Compact model/provider caption "Default model / OpenAI subscription" above or within the composer controls. Composer placeholder "Message Hermes", attachment icon, microphone, and compact square send-arrow button. No big message bubble around assistant prose. No invented online status.
Screen 3 App settings: hamburger, "App settings", small "This device". Setting groups Appearance with Theme value "System", Accent value "Mint", Text size value "Default"; Notifications with switches for "Completed work" and "Needs attention", then "Show chat titles"; About with "App version" value "Installed build". Render theme, accent and text size as disclosure rows, not pill pickers. Notifications use restrained compact switches and readable labels. Footer text "Settings apply to this device."
Every screen must fully fit within the board and all bottom actions must be visible. Keep repeated sample content identical across concepts. These are separate fully designed interfaces, not wireframes.
Concept A / FOLIO. Warm editorial direction. Palette parchment #F5F1E9, paper #FFFCF6, dark ink #252821, secondary #666A60, olive accent #526344, hairlines #D8D5CC. Flat paper surfaces. Use a beautiful restrained serif only for major page titles and the assistant's answer heading, all controls and body in a clean humanist sans. Strong left alignment, 20dp page gutters, generous vertical whitespace in conversation; compact projects separated by fine rules, no rounded cards. Structural idea: a quiet top-right rectangular outline "+ New chat" action next to Chats, search is a thin underlined field immediately under scope; all projects and chats flow as an editorial index; section labels use small uppercase tracking. Conversation user prompt shown as a simple indented paragraph with a slender olive left rule instead of a bubble. Settings groups are flat ruled lists with ample breathing room. Button corner radius 2dp; primary dark olive with off-white text, secondary thin dark border. Dark counterpart shown only as swatches and one small primary button specimen with charcoal #20231E background and pale sage accent. Title outside screens exactly "A / Folio". Avoid luxury branding tropes or textured paper.
