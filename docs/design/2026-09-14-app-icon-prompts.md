# Production icon prompts

Generated with the built-in ImageGen tool. The owner-approved reference is [03 · Playful](images/icon-expression-selection.png). The final selected standalone result is [playful-master.png](../../assets/icon/playful-master.png).

The first export contained a painted checkerboard with no alpha channel and was rejected for production. The second prompt replaces it with a navy matte. The checked-in master is the second result. Density resizing, padding and native vector export happen locally through `scripts/generate-app-icons.cjs`.
