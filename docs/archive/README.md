# Archived distribution material

`fdroiddata.yml` is the inherited upstream recipe, preserved for provenance. It refers to the upstream publisher/repository, an old release and a split-output path that its build command does not produce. It is not an active F-Droid submission for this fork. Its MIT field reflects the [upstream license identification](../../NOTICE.md).

If F-Droid distribution is selected later, create and test a current recipe with the correct publisher, source, package identity, output and confirmed license. The existing ABI version-code scheme remains in Gradle for upgrade compatibility.

`ANDROID_RELEASE_PLAN_2026-09-06.md` preserves the original release notes and subsequent dated additions. Use [the current release guide](../ANDROID_RELEASE_PLAN.md) for new work.
