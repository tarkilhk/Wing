# Stay in the loop

Wing can alert you when a connected chat finishes or needs an answer. It uses Android notifications while it monitors active work; Hermes continues accepted work on the server when you leave Wing.

## Turn on alerts

Open **App settings → Notifications** and allow Android notifications. Choose the reply and attention alerts you want. **Test notification** checks that Android can display an alert on your phone. For screen-off delivery, allow background battery use if Wing asks.

Tap an alert to open its chat. Supported approvals can be reviewed from the notification; Android requires unlocking before an approval action. You can hide message previews in Wing's notification settings.

Monitoring stops when the work it is watching ends. If you restart the phone or force-stop Wing, reopen it to restore its connection. Very short turns in chats you have not opened may not produce an alert.
